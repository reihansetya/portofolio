# Product Overview

Personal portfolio website for Reihan Setya Abida, a Front End Developer. The site showcases professional experience, technical skills, projects, and provides a contact form.

## Key Pages

- **Home** — Hero section with intro, experience timeline, and skills display
- **Project** — Gallery of past projects with browser mockup previews and modal details
- **Contact** — Email contact form powered by EmailJS

## Design Language

- Dark theme (DaisyUI "dracula" theme)
- Glassmorphism effects for elevated UI elements
- Smooth page transitions and scroll-triggered animations
- Responsive layout with mobile-first considerations
